日期：2026-11-10。Unity 6000.3.27f2，Windows x64，測試桌面 1920×1080。

## 自動化規則與保存

完整 EditMode 測試 48 項全部通過，包含 9 項玩家設定測試案例：顯示預覽期限與取消、較小螢幕的尺寸修正、非法數值修正、預覽期間保存音量、損壞／不支援版本的設定回退、缺失欄位預設與原子檔案替換。既有農場規則與保存測試同時通過。

## 場景與操作

設定 UI 已預存於 `Assets/Scenes/Farm.unity`，保留既有物件與 GUID，Inspector 明確指定服務、控制項與背景群組。場景新增設定入口、模式與解析度控制、三個音量滑桿、預覽及恢復預設確認框；音樂控制明確標示目前沒有背景音樂。

`Tools/Development/VerifyPlayerSettingsUI.cs` 在隔離的 QA 農場與設定檔執行 Play Mode 驗證，以 EventSystem raycast 點擊實際 Button，確認背景無法被誤點、背景 CanvasGroup 被鎖定及恢復、滑桿音量乘算與靜音、預覽取消、恢復預設確認／取消，以及未套用顯示選擇關閉後丟棄。另透過 EventSystem Cancel 傳遞驗證設定開啟及最上層確認優先，避免同一幀關閉交易或重開確認後又打開設定。驗證期間實際推進 89 幀。

設定畫面經 Editor Game View 擷取並檢視，滑桿把手、文字與按鈕無重疊，維持既有英文介面與視覺風格。圖片位於本機 `docs/local/validation/settings-playmode.png`。

## 獨立 Windows Player

`Tools/Development/BuildPlayerSettingsQA.cs` 建立驗證版；`PlayerSettingsStandaloneCheck` 僅在 Development Build 編譯，且只有明確傳入 `-settings-qa` 才執行。使用獨立合成設定與農場檔，不讀寫正常玩家存檔。

驗證包括：

- 初始視窗 1280×720；實際切換 1280×720、1600×900、1920×1080。
- 無邊框全螢幕實際使用 1920×1080 桌面尺寸；取消及保留切換均正確。
- 以真實時間等待超過 15 秒後，自動恢復已確認視窗。
- 總音量與音效音量相乘；任一為零時 AudioSource 增益為零。
- 開啟設定時種植物進度持續增加；建立新農場不清除設定。
- 重開後音量與已確認的視窗設定保留。
- 在未確認的無邊框預覽中退出，再重開恢復已確認的 1280×720 視窗化，連續兩輪通過。
- 合成損壞設定回到預設並提示，農場仍正常載入。

啟動階段另處理 Windows 可能在模式切換後才恢復舊視窗尺寸的情況：服務於啟動後短暫重套用已確認值，避免 Unity 的上次視窗狀態覆蓋玩家設定。

驗證版與正式 Windows 版皆建置成功，0 errors、0 warnings。正式交付位置為 `Builds/GrowWhatever-Windows/GrowWhatever.exe`，驗證報告保留於本機 `Builds/Settings-QA/settings-qa-*.json`。

## 限制與安全檢查

- 1440p、4K、低於 720p 的實體螢幕與多螢幕熱插拔未實測；可選清單、尺寸修正與極小螢幕 fallback 以規則測試涵蓋。
- 隱藏 Windows 視窗的 ScreenCapture 為黑圖，未作為視覺驗收證據；外觀以 Editor Game View 檢查。獨立 Player 的顯示驗證讀取實際 Screen 尺寸與模式。
- 音量驗證涵蓋播放來源的即時增益，未進行外部音訊回錄。沒有背景音樂素材，因此只驗證其控制值與保存。
