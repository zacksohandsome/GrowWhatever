# 首版架構與取捨

## 規則與資料

`GrowWhatever.Core` 不參照 Unity。`FarmGame` 持有九田、種子／產物庫存與金錢；同一模型的 partial 檔案依責任拆成種植經濟、加工研究／升級，以及快照驗證。介面不直接修改這些狀態。

`GrowableDefinition` 存放種植物數值與成長／成熟圖片；`FarmConfiguration` 集中開局資源、配方、研究、升級與定時存檔間隔。啟動時轉成不可變規則物件，執行時狀態與 ScriptableObject 分離。

一般種植物共用成長規則。`MoonflowerGrowthEffect` 是獨立的相鄰增益行為；它排除增益來源植物、只接受上下左右鄰接，同類效果不疊加。沒有因普通植物的數值差異而建立種類子類別。

## 時間與交易邊界

`FarmSession` 持有模型、UTC 結算時間及單一存檔服務。每個玩家命令先結算舊狀態的經過時間，再改變田地、研究或升級，避免新增增益回溯影響先前成長。

成長進度是基礎工作秒數；每秒增加「鄰田倍率 ÷ 生長升級時間倍率」。產量升級在收成時生效。`FarmGame.Advance` 同時推進既有植物和加工工作，讀檔後離線也使用它。加工依 FIFO 接續消耗剩餘時間，不建立額外工作。

研究、升級及下單先驗證完整成本／容量，再一次扣除，失敗不部分付款。收成清空田地並保留田地的批次設定；重複收成不再給資源。里程碑只保留已達成旗標，不另發資源獎勵。

## 呈現與操作

`Farm.unity` 預先擺放九塊 `FarmPlot` Prefab。每田有固定互動 Rect，植物圖片不接收 raycast。田地按地面列順序繪製，下方列後畫；高植物不改變互動範圍或排序依據。

商店、加工及研究面板與各列 Prefab 都已儲存，可在 Inspector 與場景編輯器調整。Runtime 元件只綁定參照、訂閱／解除事件和更新內容，不在執行時建立 UI 階層。`FarmAudio` 接受操作結果並播放明確指定的素材，批次操作只播一次回饋。

## 存檔

`FarmSnapshot` 包含版本、保存時間、所有資源、田地穩定 ID／植物／進度／設定、加工佇列、研究、升級與歷史旗標。`FarmGame.Restore` 驗證完整快照後才交付模型，拒絕負資源、重複／未知識別、不合法進度、缺少前置研究或不合法工作佇列。

`FarmSaveStore` 負責 JSON 與檔案讀寫。寫入同目錄暫存檔並 flush，完成後替換正式檔；讀取失敗不自行寫入或刪除原檔。需要明確確認重開才可替換損壞或不支援的存檔。首版不實作雲端、歷史備份、自動版本遷移或防作弊。

## 玩家設定

`PlayerPreferences` 定義玩家顯示與音量資料、合法解析度及數值修正；`DisplayPreview` 隔離待確認與已確認的顯示值。15 秒預覽以不受遊戲時間倍率影響的時鐘推進，確認前不把顯示值寫入保存資料，因此調整音量或在預覽期間退出都不會意外保存預覽。

`PlayerPreferencesStore` 以獨立的版本化 JSON 原子保存設定，不接觸農場存檔。`PlayerSettingsService` 管理螢幕切換、螢幕尺寸變更與音量；`PlayerSettingsView` 綁定已存入場景的 uGUI 物件，保護背景輸入並處理最上層確認與 Esc。`FarmAudio` 訂閱音量變更，總音量與音效音量相乘後套用於既有 AudioSource，保留素材原本的相對音量；預留的音樂 AudioSource 由服務套用總音量與音樂音量。

Windows 驗證入口僅存在於 Development Build，且需明確的 `-settings-qa` 參數；它使用固定的合成 QA 設定與農場存檔，正式版排除該入口。詳細驗收與硬體限制見 [玩家設定驗證](player-settings-verification.md)。

## 驗證與工具界線

EditMode 測試涵蓋種植、資源、FIFO、增益、升級、快照及原子檔案保存。Editor 操作驗證檢查 raycast、面板、Prefab 與素材。獨立 Windows QA Player 使用正常初始資源與真實經過時間，另驗證離線重開；模擬流程只供快速檢查數值，與真實試玩分開記錄。

QA 決策器只在 Editor／Development Build 編譯；獨立 QA 入口還需明確測試參數及 QA 存檔名稱，避免碰到正常存檔。正式版排除 QA 入口，也不包含 Runtime Pipeline 命令服務。首版沒有引入 DI 框架或額外工具套件。
