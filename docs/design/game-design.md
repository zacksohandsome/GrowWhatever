# GrowWhatever 首版遊戲規格

狀態：五輪訪談確認的首版範圍。初始數值見 balance.md，數值為待試玩的提案；本文件不表示已完成遊戲實作。

## 目標與範圍

一週內完成可於 GitHub 展示的電腦單機作品。主要樂趣是發現非常規種植物，次要樂趣是生產最佳化。首版目標遊玩時間約二十至三十分鐘，需以試玩驗證。

首版包含一個農場場景、九塊固定田地、四種種植物、種子商店、一個加工設施、兩個研究項目、兩項升級、存讀檔及離線進度。

不包含戰鬥、每日任務、成就系統、育種、品質、隨機掉種、物流、自動循環種植或 Steam 整合。

## 畫面與操作

- 單純 2D 正面視角、固定鏡頭，完整看見 3 × 3 九塊田。
- 採溫暖奇幻插畫風，圖片先以生圖功能製作，音效由使用者提供暫用素材。
- 每塊田有固定且互不重疊的互動範圍，植物圖片高度不擴大該範圍。
- 視覺排序依田地地面錨點，不依圖片頂端；越靠近畫面下方，植物越優先顯示。高植物跨越其他田的畫面時仍遵守此排序。
- 顯示空田、成長中、成熟三種狀態；每種植物先做成長中與成熟圖片，不做多階段動畫。
- 主畫面顯示田地、金錢、目前選擇的種子與庫存、一鍵播種、一鍵收成、目前研究／里程碑目標。
- 商店、研究、加工以面板開啟；個別田地可播種、手動收成及切換「納入一鍵收成」。

## 種植與收成

- 開局即可購買胡蘿蔔與小麥種子；其他種子先研究解鎖購買資格。
- 每塊空田播種消耗一顆庫存種子，不於播種時另扣金錢。
- 一鍵播種使用目前選擇種子，播種數量為空田數量與種子庫存的較小值；操作前顯示可播數量。
- 農田有固定順序：由上至下、同列由左至右；批次播種依序填入空田，不覆蓋既有植物。
- 成熟後不枯萎、不自動收成、不自動重種；收成取得產物並清空該田。
- 每塊田預設納入一鍵收成；關閉後批次收成略過該田，仍可手動收成。
- 批次收成設定跨收成、重種與存讀檔保留，不由植物種類自動切換。
- 首版不提供剷除未成熟植物。

## 四種種植物

| 種植物 | 種植產物 | 用途 |
| --- | --- | --- |
| 胡蘿蔔 | 胡蘿蔔 | 入門收入、研究材料 |
| 小麥 | 小麥 | 加工麵粉、販售 |
| 鐵芽 | 鐵礦 | 加工零件、販售 |
| 月光花 | 月光精華 | 鄰田增益、里程碑、販售 |

月光花播下後立即加快上下左右相鄰田地的生長，成熟後仍生效，收成後消失。不影響其他月光花，同類效果不疊加。保留增益的方式是由玩家關閉該田的批次收成設定。

增益按實際生效期間累積進度。新增、移除增益或購買成長升級前，先以舊狀態結算到操作時間，再套用新狀態，不回溯修改先前進度。

## 商店與資源

- 已解鎖種子使用金錢購買，首版供應不限量，金錢與庫存不得為負數。
- 所有產物與加工品可按固定價格販售；種子可原價賣回，不設市場波動。
- 研究及升級付款前顯示完整成本；資源不足不扣除任何材料。
- 無自動販售，重要操作後更新庫存與可用操作狀態。
- 免費補給條件：金錢不足購買最便宜已解鎖種子，且沒有任何種子、田中植物、可販售物品或已扣料的加工工作。符合時可領取一顆胡蘿蔔種子，領取後不再符合條件；不另設每日限制。

## 加工、研究與升級

- 配方只有「小麥 → 麵粉」與「鐵礦 → 零件」，不做多層材料鏈。
- 一個工作槽加三個等待工作，先進先出；每個工作執行一次配方。開始與排隊時皆須有材料及容量，下單立即扣材料。
- 完成後成品直接進庫存，下一工作接續開始。首版不做取消、退款或手動領取。
- 研究消耗材料與金錢，立即解鎖種子購買資格，不設研究倒數。
- 兩項永久升級各只有一級：縮短生長時間、提高收成量。

## 推進流程與首版終點

1. 使用胡蘿蔔與小麥，熟悉個別及批次種植、販售。
2. 加工麵粉，配合胡蘿蔔與金錢研究鐵芽。
3. 種鐵芽取得鐵礦，加工零件。
4. 使用零件研究月光花並購買至少一項種植升級。
5. 種下月光花，讓至少一塊相鄰非月光花田地實際累積增益成長進度，再手動收成一份月光精華。
6. 同時滿足月光花解鎖、至少一項升級、曾實際使用鄰田增益、取得過月光精華，顯示「首版目標完成」。達成後仍能繼續經營。

里程碑使用曾達成旗標，不因販售月光精華或收成月光花而倒退。

## 時間與存檔

- 背景運作與離線均推進既有植物及已排隊加工，不自動播種、收成、購買或下加工單。
- 不額外設定離線收益倍率或上限：有限田地、成熟封頂及有限佇列自然限制產出。
- 離線以保存配置推進；月光花在離線期間不會自動收成或移除。
- 負時間差視為零，首版不實作防作弊；系統時間往前調可能加速完成既有工作。
- 本機單一存檔，含版本、保存時間、金錢、種子與物品庫存、農田識別及狀態、成長進度、批次收成設定、加工佇列、研究、升級及里程碑旗標。
- 重要狀態操作後與定時儲存；不只依賴關閉遊戲時儲存。
