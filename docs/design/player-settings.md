# 玩家設定規格

狀態：三輪訪談及邊界行為已於 2026-11-10 確認，使用者已授權實作。驗證紀錄見 [玩家設定驗證](player-settings-verification.md)。

## 範圍

- Windows 桌面版，提供解析度、視窗模式、總音量、音樂音量、音效音量、設定保存與恢復預設值。
- 本次不新增背景音樂素材、語言、畫質、幀率上限或按鍵設定。
- 現有遊戲尚無背景音樂，音樂滑桿可調整並保存，旁邊標示「目前無背景音樂」。

## 入口與互動

- 農場主畫面提供設定按鈕，Esc 可開啟或關閉設定。
- 設定開啟時阻擋背後農場及其他面板的滑鼠與鍵盤操作。
- 種植、加工及既有時間推進持續進行，不因開啟設定而暫停。
- 顯示設定為待套用值，音量為立即生效值。

## 顯示

- 模式為視窗化與無邊框全螢幕，不提供獨佔全螢幕。
- 視窗化解析度候選為 1280×720、1600×900、1920×1080、2560×1440、3840×2160，只顯示目前螢幕可容納的項目。
- 首次啟動預設 1280×720 視窗化。
- 無邊框全螢幕跟隨目前螢幕的桌面解析度，解析度選單停用並說明原因；仍記住上次確認的視窗解析度。
- 按套用後切換顯示並顯示 15 秒倒數；按保留變更才保存，取消或逾時恢復先前已確認值。
- 已保存的顯示設定在重開遊戲後恢復。

## 音量

- 三個滑桿皆為 0–100%，0 表示該範圍靜音。
- 預設為總音量 100%、音樂 70%、音效 70%。
- 總音量同時控制音樂與音效，各分類音量再與總音量相乘；現有素材播放時既有的相對音量保留。
- 滑桿操作立即生效並保存，不受顯示設定取消或逾時復原影響。
- 未來的背景音樂需接入音樂音量控制；本次驗證其數值可調整及保存，無音樂素材可供聽感驗收。

## 保存與恢復預設值

- 玩家設定獨立於農場存檔；新農場不清除設定，恢復設定也不影響農場進度。
- 恢復預設值先要求確認。取消時沒有變更；確認後音量立即回到預設並保存，顯示設定回到預設並進入相同的 15 秒預覽流程。
- 若顯示復原，已恢復的音量仍維持預設。

## 已確認的邊界行為

- 關閉設定時丟棄尚未套用的顯示選擇，已立即保存的音量保留；顯示預覽中按 Esc 則先取消預覽並復原，留在設定畫面。
- 其他確認對話框開啟時，Esc 優先處理最上層對話框，不同時開啟或關閉底下的設定；既有強制存檔復原流程不可被 Esc 繞過。
- 顯示預覽未確認就退出遊戲，下次啟動仍用上次已確認值；倒數不因視窗失去焦點而停止。
- 換螢幕後原視窗解析度無法容納時，退回可容納且不大於原尺寸的最大候選值；若所有候選值皆無法容納，使用桌面解析度的無邊框全螢幕。UI 顯示簡短提示，操作按鈕仍可使用。
- 設定缺失時使用預設；設定格式損壞時安全回到預設並提示，不能因此阻擋農場載入。可讀的個別非法值使用預設或合法範圍修正，音量限制在 0–100%。
- 保留現有可調整視窗大小的能力；手動拖曳大小不新增解析度選項，也不覆寫上次由設定介面確認的視窗解析度。
- 設定介面沿用現有 UI 的語言及視覺風格，本次不另做多語系。

## 製作要求

- 沿用專案現有 uGUI；介面階層與版面預存於 Scene／Prefab，可在 Unity 編輯器調整，使用 Inspector 明確指定參照。
- 不在執行時逐一建立設定 UI 物件取代預存資產。
- 保留現有資產 GUID、農場存檔及時間推進規則。

## 驗收

1. 首次啟動顯示預設模式、尺寸與三組音量；設定按鈕及 Esc 可操作，背後農場無法被誤點，時間仍正常推進。
2. 視窗解析度清單符合螢幕限制；切換無邊框全螢幕後使用桌面解析度且不能另選解析度；切回視窗化可恢復上次確認的尺寸。
3. 顯示變更可保留、取消、15 秒逾時復原；失焦仍倒數；預覽期間退出後重開使用先前已確認值。
4. 音量立即生效，總音量與音效任一為 0 時操作音效靜音；音樂數值可保存且明確標示目前沒有音樂。
5. 重開遊戲與建立新農場後設定保留；取消顯示變更不復原已保存的音量。
6. 恢復預設值的確認、取消、音量保存與顯示預覽符合規格，農場進度不變。
7. 設定缺失、格式損壞、非法數值及螢幕尺寸變更皆能安全啟動並操作；最低候選解析度下介面無遮擋或無法觸及的按鈕。
8. 自動檢查涵蓋設定驗證與復原狀態轉移；Unity Play Mode 與 Windows 實際建置驗證 UI、顯示切換及音效。無法實際驗證的硬體情境如實列出。
