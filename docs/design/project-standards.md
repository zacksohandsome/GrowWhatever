# 專案製作規範

狀態：五輪訪談已確認的規範。實作已開始；本文件定義製作要求，不代表全部功能已完成驗收。

## 資產管理

- 資產直接在 Assets 下依分類資料夾管理，例如 Art、Audio、Prefab、Scripts、Scenes、Data、Editor、Tests；有實際資產時再建立目錄。
- 不建立 Assets/_Project 作為遊戲資產根目錄。
- 分類內可依功能建立子目錄，第三方素材保留來源與授權資訊，避免與自製資產混淆。
- 保留 Unity .meta 檔及資產參照，不任意重新產生 GUID。

## 場景、Prefab 與 UI

- 農田位置預先擺於場景；農田包含土壤、種植物圖片與相關功能元件，製作成 Prefab。
- 物件階層、外觀、版面配置可直接在 Unity 編輯器檢視及調整。
- 允許 Codex 透過編輯器工具建立並儲存場景與 Prefab；完成後遊戲直接使用已儲存資產。
- 不以執行時程式逐一建立 UI GameObject、文字、圖片及版面，取代可編輯的 UI 資產。
- 重複 UI 項目可 Instantiate 既有項目 Prefab；程式負責綁定資料、事件及更新顯示。
- 優先 Inspector 明確指定參照，避免依賴到處搜尋場景物件。

## 首版範圍與交付

- 約一週完成電腦單機首版，以完整循環、特色植物、存讀檔及離線進度為優先。
- 範圍為一個正面 2D 農場場景、九塊固定田地、四種種植物、一個研究介面、一個加工介面、兩項單級升級。
- 田地互動範圍互不重疊；植物依田地地面錨點排序，靠近畫面下方者優先顯示，不受圖片高度影響。
- 首版已由六種收斂為四種；時間不足再縮減升級及配方數量、視聽效果，展示影片可延後。刪減時同步調整研究依賴及驗收。
- 圖片使用生圖功能製作，音效先由使用者尋找暫用素材；公開前確認實際素材授權與待上傳內容。
- Git 與上傳檢查遵守 AGENTS.md 及 Tools/Security/README.md，保留既有 hooks。

## 驗收

- 核心規則以有意義的 EditMode 測試驗證；畫面、場景、Prefab 與 UI 在 Play Mode 操作驗收。
- 驗證收成不重複發獎、資源不為負數、在線與離線推進一致、存讀檔正確恢復。
- 可玩內容與階段終點見 [首版遊戲規格](game-design.md)。
